# Генератор случайных цитат

Учебный проект по МДК 02.02 «Инструментальные средства разработки ПО».

## Назначение
Приложение выбирает случайную цитату из набора и выводит её пользователю.

## Архитектура: как модули передают данные

Минимальный функционал (MVP) обеспечивают два независимых модуля.

1. **Модуль № 1 — парсер данных** (`src/modules/quote_storage.py`, класс `QuoteStorage`).
   Вход: путь к файлу `data/quotes.json`.
   Выход: список цитат — `[{"text": "...", "category": "..."}, ...]`.
   Модуль сам проверяет структуру файла: записи без текста пропускаются,
   отсутствующий файл и битый JSON дают понятную ошибку `QuoteStorageError`.

2. **Модуль № 2 — генератор цитат** (`src/modules/quote_generator.py`, класс `QuoteGenerator`).
   Вход: список цитат (результат работы Модуля № 1) и необязательная категория.
   Выход: одна случайная цитата — `{"text": "...", "category": "..."}`.

Схема передачи данных:

```
                 data/quotes.json
                        │
                        ▼
        ┌───────────────────────────────┐
        │  Модуль № 1 «Парсер данных»   │
        │  QuoteStorage.load()          │
        └───────────────┬───────────────┘
                        │  список цитат
                        ▼
        ┌───────────────────────────────┐
        │  Модуль № 2 «Генератор»       │
        │  QuoteGenerator               │
        │  .random_quote(category)      │
        └───────────────┬───────────────┘
                        │  одна цитата
                        ▼
        ┌───────────────────────────────┐
        │  main.py + ui.py              │
        │  вывод пользователю           │
        └───────────────────────────────┘
```

Связующий код находится в `src/main.py`: он читает настройки из
`config.json`, получает список цитат из Модуля № 1 и автоматически
передаёт его на вход Модулю № 2.

## Структура
- `src/main.py` — точка запуска и связующий код;
- `src/modules/quote_storage.py` — Модуль № 1: загрузка и проверка цитат;
- `src/modules/quote_generator.py` — Модуль № 2: случайный выбор цитаты;
- `src/modules/category_manager.py` — работа с категориями;
- `src/modules/config.py` — чтение конфигурации;
- `src/modules/ui.py` — взаимодействие с пользователем;
- `data/quotes.json` — набор цитат;
- `tests/` — модульные и интеграционный тесты;
- `conftest.py` — настройка путей для запуска тестов.

## Запуск

```bash
python src/main.py
```
